# Меню

## Стиль
- Окно фиксированного размера 860×580, открывается по центру. Есть тень, градиентная кромка сверху и акцентная подсветка шапки.
- Шрифт: Bahnschrift из `C:\Windows\Fonts`. Недостающие символы берутся из Segoe UI и Segoe UI Symbol.
- Акцентный цвет настраивается (Settings → Theme, плюс 6 пресетов) и сохраняется в настройках.

## Иконки
`ui/svg.cpp` — свой парсер SVG path (M L H V C S Q T A Z), отрисовка сглаженными линиями `ImDrawList`. Иконки и логотип — собственные пути 24×24 в `ui/icons_svg.h`. Шестерёнка строится как многоугольник с 8 зубьями.

## Виджеты (`ui/ui.cpp`)
- **Feature:** строка функции с переключателем. Шестерёнка или ПКМ открывает поповер с настройками и биндом (клавиша, Toggle/Hold/Always).
- **Slider:** трек 4 px, ручка со свечением, значение справа, ширина по карточке.
- **Прочее:** Combo с SVG-стрелкой, ColorEdit (свотч и пикер), Segmented (подвкладки с анимированной плашкой), Button (Normal/Primary/Destructive), Card, Value, Note.
- **Тосты:** правый нижний угол, берутся из лога.

## Анимации
Открытие и закрытие окна (прозрачность и сдвиг), смена страниц, наведение, переключатели, поповеры, плашка подвкладок. Settings → Theme → Reduce animations отключает их.

## Скины
- **Inventory:** чипы-фильтры, поиск, сетка карточек на всю ширину с подсветкой по редкости и бейджами T/CT/ST, клик открывает поповер экипировки.
- **Add:** чипы категорий, выбор оружия, поиск, окно добавления (превью, износ, паттерн, StatTrak, неймтег, 5 стикеров, команды).

## Рендер (`ui/render.cpp`)
Свои примитивы поверх `ImDrawList` (через `PrimReserve`/`PrimWriteVtx`):
- `Gradient`: скруглённый прямоугольник с градиентом по вершинам (вертикальный или горизонтальный) и кромкой сглаживания 1 px.
- `Shadow`: мягкая тень из нескольких колец с квадратичным затуханием.
- `Glow`: радиальное свечение с гауссовым затуханием, 96 сегментов, без видимых колец.
- `Border`, `Circle`, `Text`: обводка по полупикселю, круг с адаптивным числом сегментов, текст с привязкой к пикселю.
Карточки, кнопки, переключатели, слайдеры, плашка подвкладок, фон окна и подсказки рисуются через этот слой.

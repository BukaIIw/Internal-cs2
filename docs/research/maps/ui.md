ITEM ICON TEXTURES (icons.cpp)
- Worker thread (COM MTA + WIC factory) reads VPK files (vpk::Read), decodes Source 2 VTEX (see game_facts), downsamples RGBA with alpha-weighted 2x2 box filter until w <= 160, BC1/BC3 uploaded as-is at the first mip <= 256 wide. Requests are LIFO (newest first). Render thread: icons::Frame() (only while menu visible) uploads up to 24 finished images per frame as D3D11_USAGE_IMMUTABLE single-mip textures, LRU-evicts when cache > 400 entries down to 300 (entries unused for >2 frames). icons::Get(path) returns SRV as uint64 or 0 and enqueues.

ESP (visuals.cpp)
- visuals::Render on Present thread, guarded by game::Ready() and SEH. Uses ImGui::GetBackgroundDrawList(). Loops controller indices 1..64 (designer "cs_player_controller"), skips local index/pawn, health<=0, missing scene node, dormant; team filter via m_iTeamNum (uint8). Draws box (with 2 black outlines), health bar (6..3 px left of box, red->green), HP number when <100, name (m_sSanitizedPlayerName) above, weapon name and distance (meters) below, skeleton (16 bone pairs, 1.2 px), snaplines from bottom center, FOV circle (white alpha 90, 64 seg). Color by team / visibility::Visible(pawn) (visibility cache computed on game thread at stage 7).

GLOW (glow.cpp)
- Runs on FrameStage stage 7 (game thread), after Visibility (subscription order wiring.cpp). Writes CGlowProperty fields on each wanted pawn every frame after saving the originals per slot (1..64); restores when the pawn is no longer wanted / replaced / feature disabled / unload. Colors packed RGBA (R in low byte).

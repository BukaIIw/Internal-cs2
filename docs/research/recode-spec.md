## Global rules
- Code style: like the owner reference. snake_case functions/variables, `m_` members, `g_` globals, namespaces `memory::`, `addresses::`, `schema::`, `convars::`, `systems::`, `features::...`. Brace style: Allman, 4 spaces. NO comments in code (owner preference). No `TODO`s, no placeholders, no dead code.
- Game memory access only through `memory::read/write/ref/call/call_vfunc` and `SCHEMA("Class", "m_field"_hash)` for netvars, `PATTERN(patterns::name)` for addresses, `CONVAR("name")` for cvars, `INTERFACE_("module.dll:Name")` for interfaces. Never store a resolved address in your own global; call `PATTERN(...)` at the use site (it is cached internally). Raw non-schema offsets are allowed only as named `constexpr` in an anonymous namespace at the top of the .cpp that uses them, and only when they come from the research files (cite nothing in code, but list them in your final report).
- Entities are `std::uintptr_t` (like the reference), not typed classes.
- Everything that touches game memory from a feature runs inside an event handler. The event bus wraps every handler in SEH (`__try/__except`), so features do not add their own SEH except where a single game call is known to be fragile and a fallback exists.
- Do not include any OLD header (`game.h`, `mem.h`, `misc.h`, `input.h`, `aim.h`, `ragebot.h`, `skins.h`, `hands.h`, `glow.h`, `visuals.h`, `damage.h`, `visibility.h`, `movement.h`, `hooks.h` in src root, `core/ray.h`, `core/usercmd.h`, `core/wiring.h`, `features/{schema,hitbox,spread,nospread,jumpcheck,attack,vecmath}.h`, root `menu.h`). They will be deleted. You may read them for knowledge. Allowed old modules that stay: `items.*`, `kv.*`, `vpk.*`, `icons.*`, `ui/svg.*`, `ui/icons_svg.h`, `core/log.*` (logs::Add API).
- Headers already written by the architect and FROZEN (do not change their public API; if something is truly missing, add new free functions in your own new header and mention it in the report): `src/core/{hash,memory,addresses,patterns,schema,convar,math,cstypes,events,hooks,keys,settings}.h`, `src/systems/*.h`, `src/features/{features.h,features.cpp,combat/combat.h,movement/movement.h,changer/changer.h,visuals/visuals.h,misc/misc.h}`, `src/ui/menu.h`, `src/ui/fonts.h`, `src/ui/render.h` (existing painter API: functions may be added, existing ones keep their signatures). `core/patterns.cpp` is generated (owner list + extras) — do not edit except to fix a broken string.
- Syntax check every file you write: `python3 ~/.claude/tools/cxxcheck.py <files...>` from the repo root (clang + mingw headers; mirrors MSVC loosely). Zero errors required. It cannot link, so also re-read your code for ODR/missing definitions: every declared function in the frozen headers that belongs to your module must be defined exactly once.
- Threads: game thread = FrameStageNotify/CreateMove; render thread = Present (same thread in CS2 usually, but do not rely on it). Anything read in Present must come from a snapshot guarded by a mutex or atomics (`systems::g_entities.players()`, `systems::g_local.get()`).

## Pattern syntax (owner) and resolver — `core/memory.cpp`, `core/addresses.cpp`
Spec string: `"module.dll:HEX..."` where body = sequence of `HH` byte pairs, `??` wildcard, at most one zero-width marker `*` or `>`, optional suffix `+HEX` / `-HEX` (hex offset), optional final `~`.
Resolution: find first match in module `.text` (executable sections) → `addr = match`; if `*` at byte index i: `addr = match + i + 4 + int32(match+i)`; if `>` at i: `addr = match + i + 5 + int32(match+i+1)`; then `addr += offset`; then if `~`: `addr = *(uintptr_t*)addr` (check readable first; if the read gives 0 treat as unresolved-retryable). `memory::resolve_pattern(spec, &matches)` returns 0 on failure and fills match count (count up to 2 for uniqueness).
`addresses::resolve(entry)`: cache in `entry.cached`; if 0 and the spec has `~` or the module was not loaded, retry on later calls (rate-limit: at most once per 500 ms per entry); otherwise resolve once and record status. `resolve_all()` warms every entry from `patterns::all()` on the loader thread and logs a summary (`logs::Add`).
Registry/dev tooling (`snapshot/verify/generate/generate_at/generated_custom/busy/export_list/shutdown`): port from the old `src/core/patterns.cpp` (see `git show HEAD:src/core/patterns.cpp`): worker thread, verify by counting matches in the on-disk module image (so MinHook patches don't interfere), hde64-based unique signature generator that now EMITS OWNER SYNTAX (`HEX`, `??`, rel/rip disp wildcarded), export to `%APPDATA%\Internal-cs2\patterns.txt`. hde64 header: `#include "../../deps/minhook/src/hde/hde64.h"` (as before).
`addresses::globals::*` (each cached, retrying while 0):
- `schema_system()` = `INTERFACE_("schemasystem.dll:SchemaSystem_001")`
- `cvar()` = `INTERFACE_("tier0.dll:VEngineCvar007")`
- `localize()` = `INTERFACE_("localize.dll:Localize_001")`
- `engine_client()` = `INTERFACE_("engine2.dll:Source2EngineToClient001")`
- `source2_client()` = `INTERFACE_("client.dll:Source2Client002")`
- `entity_system()` = `*(uintptr_t*)PATTERN(patterns::entity_list_legacy)` (proven, see entities), fallback `*(uintptr_t*)PATTERN(patterns::game_entity_system)`.
- `global_vars()` = `*(uintptr_t*)PATTERN(patterns::global_vars)` (mov-style global: the pattern returns the address of the pointer).
- `csgo_input()` = `PATTERN(patterns::csgo_input)` (lea-style: object itself).
- `item_system()` = `memory::call<std::uintptr_t>(PATTERN(patterns::item_system))` (function returning CCSItemSystem*; schema = `*(item_system()+0x8)`).
- `trace_manager()` = `*(uintptr_t*)PATTERN(patterns::game_trace_manager_legacy)` (proven), fallback `PATTERN(patterns::game_trace_manager)` (already dereferenced by `~`).
- `view_matrix()` = `PATTERN(patterns::view_matrix)` (lea of float[4][4] array, slot 0), fallback `call(view_matrix_fn, 0)`.
`get_module_interface("mod:Name")`: `GetProcAddress(mod, "CreateInterface")(name, nullptr)`. `get_module_export("mod:Export")`. `find_vtable(module, ".?AVName@@")`: port old `mem::VTable` (RTTI COL scan) from `git show HEAD:src/mem.cpp`. `is_readable`: VirtualQuery-based with a small cache, or SEH probe.
`hash::murmur2_lower`: lowercase MurmurHash2 (m=0x5bd1e995, r=24), see `docs/research/ref/knives.cpp`; `make_subclass_token(def) = murmur2_lower(std::to_string(def), 0x31415926)`.

## Schema — `core/schema.cpp`
No schema system existed before. Implement via `SchemaSystem_001`:
- `type_scope = call_vfunc<uintptr_t>(schema_system, 13, "client.dll", nullptr)` (FindTypeScopeForModule).
- `call_vfunc<void>(type_scope, 2, &class_info, "C_BaseEntity")` (FindDeclaredClass, out param `SchemaClassInfoData_t*`).
- `SchemaClassInfoData_t`: `+0x08 const char* name`, `+0x10 const char* module`, `+0x18 int size`, `+0x1C int16 field_count`, `+0x23 uint8 base_class_count`, `+0x28 SchemaClassFieldData_t* fields`, `+0x38 SchemaBaseClassInfoData_t* base_classes`.
- `SchemaClassFieldData_t` stride 0x20: `+0x00 const char* name`, `+0x08 type*`, `+0x10 int32 offset`.
- `SchemaBaseClassInfoData_t` stride 0x10: `+0x00 uint32 offset`, `+0x08 SchemaClassInfoData_t* class`.
Validate everything: class_info non-null, `strcmp(name, requested)==0`, field_count in [0, 4096], pointers readable (SEH). Search the class's own fields first, then recurse into base classes adding base offset. If client.dll scope fails for a class, also try `"animationsystem.dll"`, `"engine2.dll"`, `"scenesystem.dll"`, `"materialsystem2.dll"` scopes (needed e.g. for `CHitBox`, `CHitBoxSet`, `CModelState`?). Cache per (class, field-hash) in an unordered_map under a mutex; log each missing field once (`logs::Add(logs::Warning, ...)`) and record it for `missing()`. `class_size(name)` returns `+0x18` or -1. `initialize()` resolves the interface and scope (retry-safe), returns readiness.

## Events — `core/events.cpp`
Typed bus (see `core/events.h`). Subscribers sorted by priority (stable for equal priority), no fixed cap (std::vector per type, filled at startup before hooks are enabled, then read-only). Each call wrapped in SEH; a faulting subscriber is disabled, `logs::Add(logs::Error, "%s faulted in %s", name, event)`, stats: calls, avg/peak microseconds (QPC). `enable(type, index)` re-arms. `name(type)` returns a display name. Port from old `core/events.cpp`.

### view.cpp (`g_view`) — THE single place that changes angles and fires
Per tick: `begin(frame)` resets request/fire, stores original = frame.view(). Features call `aim(angle, silent, priority, owner)` (higher priority wins; equal priority keeps first) and `fire(when)` (when<0 → default `0.98f`, i.e. the last frame of the tick so the attack uses the newest history entry), `block_fire()` cancels any fire this tick (e.g. semi-auto needs release).
`apply(frame)` (create_move, priority view): 
- non-silent aim → `frame.set_view(angle)` and `g_input.set_view_angles(angle)`; movement is not corrected (the view really moved).
- silent aim → frame angles untouched. If firing: insert the attack press at `fire_when` and a release at `min(fire_when + 1/64, 0.999)` (`frame.press/release(in_attack)`); set the attack press event's pitch/yaw to the aim angle only if `CONVAR("sv_subtick_movement_view_angles")` is 0 (else leave event angles = view to keep movement intact).
- non-silent fire: same press/release with event angles = aim angle.
- semi-auto: if `m_last_fired` and the weapon is not full-auto (`features::combat::g_shared.ctx().full_auto`), do not fire this tick (set `m_fire=false`), so the button alternates.
`apply(cmd)` (create_move_post): if a silent request is active: for every history entry write the aim angle (if `smooth_silent`, lerp from the entry's original angle to the aim angle with t=(i+1)/n — UC 727475); base viewangles untouched (server takes the shot angle from history: UC 774174). If firing: `cmd.buttons() |= in_attack; cmd.buttons_changed() |= in_attack;` `set_base_buttons(in_attack, 0)`, `set_attack1_index(history_size()-1)` (≥0). If firing is blocked/false and the user is not holding attack: clear `in_attack` from value/changed only if we injected it last tick. `end()`: `m_last_fired = m_fire && m_applied_attack`, reset.
`correct_movement(forward, left, from_yaw, to_yaw)`: rotate the move vector so the world direction stays the same (port old `usercmd::SetAngles` math, sign as old code).
